## ✨ Why Build & Automation?

As projects grow, manual commands don’t scale.

Build and automation tools help you:

- Define **what** needs to be done instead of **how** to do it repeatedly
- Encode workflows as **version-controlled logic**
- Avoid human errors by making processes **deterministic**
- Improve developer productivity and CI/CD reliability

From compiling code and running tests to packaging artifacts and provisioning environments, automation is the backbone of modern software development.

## 🔧 Current Focus: Makefile

The Makefile is one of the oldest yet most powerful build orchestration tools.  
It is especially relevant for:

- Build pipelines
- DevOps workflows
- Embedded / firmware projects
- CI systems
- Replacing long shell scripts with declarative logic

The Makefile notes cover:

- Dependency graphs and execution flow
- Variables and evaluation timing
- Phony targets and actions
- Practical usage beyond C/C++
